# IP Box Evidence Folder

This folder is reserved for real, reviewable evidence only.

Do not add invented screenshots, usage logs, tickets, test results, hours or client evidence. Do not add confidential client data unless it has been reviewed and approved for inclusion.

Screenshots should show the real tool, date and product version where practical. Test run records should include the command, date and result. Anonymized cases must remove client secrets, production identifiers and confidential commercial data.
